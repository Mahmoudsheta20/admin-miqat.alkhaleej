# تعريب الواجهة واللغة الإنجليزية

يدعم النظام العربية باتجاه من اليمين إلى اليسار، والإنجليزية باتجاه من اليسار إلى اليمين. يحفظ اختيار اللغة محليًا وفي ملف تعريف ارتباط لكي يظهر الاتجاه المناسب عند تحميل الصفحة من الخادم. تتوفر أداة اختيار اللغة في الدخول والشريط العلوي والقائمة الجانبية.

يُستخدم خط Inter للأحرف اللاتينية وخط Zain للعربية، مع خط أحادي المسافة للأرقام والمعرّفات. تستخدم المسافات والمحاذاة خصائص اتجاهية حتى ينعكس التخطيط عند تبديل اللغة. نُقلت بطاقة ملخص الهاتف إلى التدفق الطبيعي حتى لا تحجب حقول الفاتورة.

## إضافة النصوص

- مفاتيح التنقل المشتركة في `lib/translations.ts`.
- عبارات الواجهة في `lib/ui-phrases.ts`، والقوالب ذات القيم المتغيرة في `UI_TEMPLATES`.
- تستعمل المكونات `useUiText()` للنصوص والعناوين ورسائل الخطأ وخصائص الإتاحة. تترجم تسميات الواجهة الثابتة قبل إدراجها داخل قالب متغير.
- تُستخدم `LocalizedText` للنصوص القادمة من المكونات الخادمية و`localizedMetadataTitle` لعناوين الصفحات.
- تبقى أسماء العملاء والموردين والموظفين والملاحظات وأوصاف بنود الفواتير والبيانات المحفوظة بلغتها الأصلية. لا تمررها للمترجم ولا تغيّرها عند تبديل اللغة.
- تبديل لغة لوحة التحكم لا يعيد إصدار الفواتير السابقة ولا يغيّر نسخ مستنداتها المحفوظة.

## التحقق

شغّل `npm test` و`npm run typecheck` و`npm run lint` ثم `npm run build -- --webpack`. تشمل الاختبارات اكتمال مفاتيح الترجمة، وحماية النصوص المدخلة، والقوالب المتغيرة، وأسماء الدول وأكواد الاتصال. راجع بصريًا العربية والإنجليزية على الهاتف والكمبيوتر، مع النوافذ المنبثقة والوضع الداكن.

## إزالة الفواتير

توجد إزالة قابلة للاستعادة في قائمة الفواتير وتفاصيل الفاتورة. اختر «إظهار الفواتير المزالة» لاستعادتها، وأدخل سبب الإزالة أو الاستعادة. تبقى الفاتورة وحركاتها المالية ضمن التقارير والإقرار الضريبي. تخفيض المبيعات يتم بإشعار دائن مرتبط بالفاتورة الأصلية.

يتطلب تفعيل الإزالة على السيرفر تحديث الواجهة والخلفية وتطبيق ملف `prisma/changes/20261101_invoice_visibility.sql` في مشروع الخلفية، بعد النسخ الاحتياطي. راجع `docs/INVOICE-REMOVAL.ar.md` هناك. لم يُطبق هذا التحديث على قاعدة الإنتاج أثناء تطوير الواجهة.
